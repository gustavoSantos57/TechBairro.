# Manual de uso da TechBairro

## A tela principal

A TechBairro é um sistema utilizado para cadastrar e organizar os dados dos clientes da associação de moradores.

Na tela principal, o usuário encontra os campos para preencher os dados do cliente, os botões para realizar as operações e um contador que mostra a quantidade de clientes cadastrados.

Os dados podem ser cadastrados, consultados, alterados ou excluídos conforme a necessidade.

## Cadastrar um cliente

1. Abra o programa TechBairro.
2. Preencha os campos com o nome, telefone, e-mail e endereço do cliente.
3. Confira se as informações estão corretas.
4. Clique no botão **Cadastrar** para salvar os dados.
5. Verifique a mensagem apresentada pelo sistema para confirmar se o cadastro foi realizado.

## Consultar os clientes cadastrados

1. Na tela principal, clique no botão **Consultar Clientes**.
2. Aguarde a abertura da janela de consulta.
3. Procure o cliente desejado na lista apresentada.
4. Confira as informações do cliente selecionado.
5. Quando terminar, feche a janela de consulta.

## Alterar os dados de um cliente

1. Abra a janela **Consulta de Clientes** pelo botão **Consultar Clientes**.
2. Selecione o cliente que deseja alterar.
3. Clique na opção **Editar**, caso ela esteja disponível na janela.
4. Altere as informações necessárias.
5. Clique em **Salvar** para registrar as alterações.
6. Confira se os dados foram atualizados corretamente.

## Excluir um cliente

1. Clique no botão **Consultar Clientes**.
2. Localize e selecione o cliente que deseja excluir.
3. Clique na opção **Excluir**, caso esteja disponível.
4. Confirme a exclusão, se o sistema solicitar.
5. Confira se o cliente deixou de aparecer na lista.

**Atenção:** antes de excluir um cadastro, confira se selecionou a pessoa correta, pois os dados poderão não ser recuperados facilmente.

## Regras de preenchimento

| Campo | Obrigatório? | Regra |
|---|---|---|
| Nome | Sim | Informe o nome do cliente de forma completa. |
| Telefone | Sim | Digite um número de telefone válido para contato. |
| E-mail | Sim | Informe um endereço de e-mail válido, como `cliente@email.com`. |
| Endereço | Sim | Informe a rua, o número e outros detalhes necessários para localizar o cliente. |

Os campos acima são considerados obrigatórios neste manual. Se o sistema permitir deixar algum deles vazio, confira as regras reais da versão instalada e ajuste esta tabela.

## Dúvidas frequentes

**1. O que fazer se eu esquecer de preencher um campo?**

Volte à tela principal, preencha a informação que está faltando e tente cadastrar novamente.

**2. Como encontro um cliente que já foi cadastrado?**

Clique em **Consultar Clientes** e procure o nome do cliente na lista apresentada.

**3. Posso corrigir um telefone ou endereço depois de cadastrar?**

Sim. Abra a consulta, selecione o cliente, utilize a opção de edição e salve as alterações.

**4. O que acontece se eu excluir um cliente por engano?**

Confira se o cadastro realmente foi removido e avise o responsável pelo sistema. Se houver uma cópia de segurança do banco de dados, ela poderá ajudar na recuperação.

**5. O que fazer se o programa não abrir?**

Confira se o Python está instalado e se os arquivos do projeto estão na pasta correta. Se o problema continuar, peça ajuda à pessoa responsável pela instalação.
